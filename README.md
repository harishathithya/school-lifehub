# School Life Hub 🏫

> **Everything a student needs, all in one place.**

School Life Hub is a centralized digital platform and student productivity dashboard designed specifically for school students (Classes 6–12), teachers, and school administrators.

---

## ✨ Features

- **Personalized Student Dashboard**: Welcome greeting, student profile summary, daily class count, pending homework tracker, and exam countdowns.
- **Academic Resources & Study Materials**: Subject-wise curated notes, formula sheets, previous year question papers, and chapter-wise study guides.
- **Weekly Class Timetable**: Monday–Saturday schedule with period timings, subject allocations, teacher names, room locations, and break indicators.
- **Assignments & Homework Tracker**: Add homework with due dates, subject tags, overdue indicators, and completed/pending filters.
- **Examinations Hub**: Datesheet schedules, maximum marks, syllabus portions, and a checklist revision tracker.
- **School Announcements**: Official school circulars, holiday notices, competition announcements, and pinned alerts.
- **School Events & Clubs**: Co-curricular activities, science fairs, sports days, and club memberships with teacher-in-charge details.
- **Attendance & Assessment Trackers**: Subject-wise class attendance logging with a 75% warning threshold, and assessment test mark recordings.
- **Productivity Utilities**: Built-in Pomodoro study focus timer, daily to-do checklists, and quick notebook notes.
- **Student Profile**: Custom avatars, roll numbers, class & section details, and session management.

---

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/harishathithya/school-lifehub.git
   cd school-lifehub
   ```

2. Open `index.html` in your browser, or serve it using any local static web server:
   ```bash
   python -m http.server 8080
   ```

3. Visit `http://localhost:8080/` to access the hub.
